# 機能仕様

## 機能一覧（MVP）
1. リストの作成・名称変更・削除・並び替え（D&D）
2. カードの作成・編集・削除
3. カードをドラッグ&ドロップでリスト間・リスト内移動
4. カードへの優先度設定（緊急 / 高 / 中 / 低 / なし）
5. カードへの期限設定（期限切れは見た目で分かるようにする）
6. リスト内のカードを日付順・優先度順でソート
7. データはPostgreSQLに保存（リロードしても消えない）

## MVPに含めないもの（将来拡張）
- ユーザー登録・ログイン
- 複数ボード管理
- 検索・フィルタ
- コメント・添付ファイル
- ユーザー定義ラベル
- マルチユーザー対応

## 画面構成

### メイン画面（ボード画面）
- ヘッダー：アプリ名のみ表示（設定ボタンなし）
- ボード領域：リストを横並びで表示
- リスト追加ボタン：ボードの右端に常に表示
- リストはD&Dで横方向に並び替え可能（リストヘッダーをつかんでドラッグ）

### リスト
- リストヘッダーに「リスト名」「📅 日付」「🔥 優先度」ソートボタン「⋮」を横並びで表示
- リスト名をクリック → インライン編集（Enterで確定、Escでキャンセル）
- ⋮メニュー → 「削除」のみ（確認ダイアログあり）
- 「📅 日付」ボタン → リスト内カードを期限日の昇順にソート（期限なしは末尾）
- 「🔥 優先度」ボタン → リスト内カードを優先度順（緊急→高→中→低→なし）にソート

### カード（一覧表示）
- タイトルを表示
- 優先度が設定されている場合：タイトル上部に優先度バッジを表示
  - 緊急：赤バッジ / 高：黄バッジ / 中：青バッジ / 低：緑バッジ
- 期限がある場合：タイトル下部に日付表示
  - 期限切れ：赤文字 + 背景薄赤
  - 当日：オレンジ文字
  - 期限内：グレー文字
- カードをクリック → 詳細モーダルを開く
- カードにホバー → ⋮ボタンが表示
- カードの⋮メニュー → 「↑ 上に移動」「↓ 下に移動」「削除」
- カードはD&Dでリスト内・リスト間を移動可能

### カード詳細モーダル
- タイトル（インライン編集）
- 詳細メモ（テキストエリア）
- 優先度（緊急 / 高 / 中 / 低 / なし から1つ選択）
- 期限日（date picker）
- モーダル外クリック or ✕ボタンで閉じる（変更は自動保存）
- 削除はカードの⋮メニューから行う（モーダル内に削除ボタンなし）

### カード追加
- 各リストの下部に「＋ カードを追加」テキストボタン
- クリックするとリスト下部にインライン入力欄が出現
- Enterで追加、Escでキャンセル
