# 機能仕様

## 機能一覧（実装済み）
1. ボードの作成・タブ切り替え
2. リストの作成・名称変更・削除・並び替え（D&D）
3. カードの作成・編集・削除
4. カードをドラッグ&ドロップでリスト間・リスト内移動
5. カードへの優先度設定（緊急 / 高 / 中 / 低 / なし）
6. カードへの期限設定（期限切れは見た目で分かるようにする）
7. カードのタイトル・優先度・期限日による検索・フィルタ
8. データはPostgreSQLに保存（リロードしても消えない）

## 含めないもの（将来拡張）
- ユーザー登録・ログイン
- コメント・添付ファイル
- ユーザー定義ラベル
- マルチユーザー対応

## 画面構成

### メイン画面（ボード画面）
- ヘッダー：アプリ名・ボード追加ボタン・検索バーを表示
- ボードタブ：作成済みボードをタブで横並び表示。クリックで切り替え。アクティブなボードは青いアンダーラインで強調
- ボード領域：選択中のボードのリストを横並びで表示
- リスト追加ボタン：ボードの右端に常に表示
- リストはD&Dで横方向に並び替え可能（リストヘッダーをつかんでドラッグ）

### ボード追加
- ヘッダーの「+ ボードを追加」ボタンをクリックでモーダルを開く
- ボード名を入力してEnterまたは「追加」ボタンで作成
- 作成後、新しいボードのタブが追加される

### リスト
- リストヘッダーに「リスト名」「📅 日付」「🔥 優先度」ソートボタン「⋮」を横並びで表示
- リスト名をクリック → インライン編集（Enterで確定、Escでキャンセル）
- ⋮メニュー → 「削除」のみ（確認ダイアログあり）
- 「📅 日付」ボタン → リスト内カードを期限日の昇順にソート（期限なしは末尾）
- 「🔥 優先度」ボタン → リスト内カードを優先度順（緊急→高→中→低→なし）にソート

### カード（一覧表示）
- タイトルを表示
- 優先度が設定されている場合：タイトル上部に優先度バッジを表示
  - 緊急：赤バッジ / 高：黄バッジ / 中：青バッジ / 低：緑バッジ
- 期限がある場合：タイトル下部に日付表示
  - 期限切れ：赤文字 + 背景薄赤
  - 当日：オレンジ文字
  - 期限内：グレー文字
- カードをクリック → 詳細モーダルを開く
- カードにホバー → ⋮ボタンが表示
- カードの⋮メニュー → 「↑ 上に移動」「↓ 下に移動」「削除」
- カードはD&Dでリスト内・リスト間を移動可能

### カード詳細モーダル
- タイトル（インライン編集）
- 詳細メモ（テキストエリア）
- 優先度（緊急 / 高 / 中 / 低 / なし から1つ選択）
- 期限日（date picker）
- モーダル外クリック or ✕ボタンで閉じる（変更は自動保存）
- 削除はカードの⋮メニューから行う（モーダル内に削除ボタンなし）

### カード追加
- 各リストの下部に「+ カードを追加」テキストボタン
- クリックするとモーダルが開く
- 入力項目：タイトル（必須）・メモ・優先度・期限日
- 「追加」ボタンまたはEnterで追加、「キャンセル」またはモーダル外クリックで閉じる

### リスト追加
- ボードのリスト列右端に「+ リストを追加」ボタンを常に表示
- クリックするとインライン入力欄が展開
- リスト名を入力して「追加」ボタンまたはEnterで作成、✕またはEscでキャンセル

## API エンドポイント一覧

### ボード API

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/boards` | ボード一覧取得 |
| GET | `/boards/{id}` | ボード詳細取得 |
| POST | `/boards` | ボード作成（201 Created） |
| PUT | `/boards/{id}` | ボード更新 |
| PATCH | `/boards/reorder` | ボード並び順一括更新（D&D） |
| DELETE | `/boards/{id}` | ボード削除（204 No Content） |

### リスト API

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/boards/{boardId}/lists` | 指定ボード内のリスト一覧取得 |
| POST | `/boards/{boardId}/lists` | リスト作成（201 Created） |
| PUT | `/lists/{id}` | リスト更新（タイトル・並び順） |
| PATCH | `/boards/{boardId}/lists/reorder` | リスト並び順一括更新（D&D） |
| DELETE | `/lists/{id}` | リスト削除（204 No Content） |

### カード API

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/lists/{listId}/cards` | 指定リスト内のカード一覧取得 |
| GET | `/cards/{id}` | カード単体取得 |
| GET | `/cards/search` | カード検索（`?title=&priority=&dueDate=`） |
| POST | `/lists/{listId}/cards` | カード作成（201 Created） |
| PUT | `/cards/{id}` | カード更新（タイトル・メモ・優先度・期限日・並び順） |
| PATCH | `/cards/{id}/move` | カードのリスト間移動（D&D） |
| PATCH | `/lists/{listId}/cards/reorder` | カード並び順一括更新（D&D） |
| DELETE | `/cards/{id}` | カード削除（204 No Content） |
