# データモデル

## エンティティ概要
- **ボード（Board）**: まずは固定1ボードのみ対応
- **リスト（List）**: ボード内に複数（例: TODO / 進行中 / 完了）
- **カード（Card）**: リストに属する
  - タイトル（必須）
  - 詳細メモ（任意）
  - ラベル（固定カラーセットから複数選択可）
  - 期限日（任意）
- **カードラベル（Card Label）**: カードに付与された色。固定カラーセットから選ぶ

## 固定カラーセット
| ID | 色名 | カラーコード |
|---|---|---|
| red | 赤 | #F87171 |
| yellow | 黄 | #FBBF24 |
| green | 緑 | #34D399 |
| blue | 青 | #60A5FA |
| purple | 紫 | #A78BFA |

- ユーザーがラベルを自由に作成・削除することはできない（将来拡張）
- 1枚のカードに複数の色を付与できる
- 同じ色を重複して付与することはできない
