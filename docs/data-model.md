# データモデル

## エンティティ概要
- **ボード（Board）**: まずは固定1ボードのみ対応
- **リスト（List）**: ボード内に複数（例: TODO / 進行中 / 完了）
- **カード（Card）**: リストに属する
  - タイトル（必須）
  - 詳細メモ（任意）
  - 優先度（固定の4段階から1つ選択、任意）
  - 期限日（任意）

## 優先度
カードごとに1つの優先度を設定できる。設定しない場合は「なし」とする。

| ID | 表示名 | 色 |
|---|---|---|
| urgent | 緊急 | #F87171（赤） |
| high | 高 | #FBBF24（黄） |
| medium | 中 | #60A5FA（青） |
| low | 低 | #34D399（緑） |
| none | なし | — |

- 優先度はカードの `priority` カラムに文字列で保存する
- 1枚のカードに設定できる優先度は1つのみ
