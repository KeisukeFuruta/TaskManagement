# タスク管理アプリ 要件定義（v1）

## 対象ユーザー
自分一人で使うタスク管理アプリ。ログイン機能なし。

## システム構成
- フロントエンド（React）とバックエンド（Java / Spring Boot）を分離した構成
- フロントエンドはREST APIを通じてバックエンドと通信する
- データはPostgreSQLに永続化する
- マルチユーザー対応は対象外（将来拡張）

## データモデル
- **ボード（Board）**: まずは固定1ボードのみ対応
- **リスト（List）**: ボード内に複数（例: TODO / 進行中 / 完了）
- **カード（Card）**: リストに属する
  - タイトル（必須）
  - 詳細メモ（任意）
  - ラベル（固定カラーセットから複数選択可）
  - 期限日（任意）
- **カードラベル（Card Label）**: カードに付与された色。固定カラーセットから選ぶ

### 固定カラーセット
| ID | 色名 | カラーコード |
|---|---|---|
| red | 赤 | #F87171 |
| yellow | 黄 | #FBBF24 |
| green | 緑 | #34D399 |
| blue | 青 | #60A5FA |
| purple | 紫 | #A78BFA |

## 機能（MVP）
1. リストの作成・名称変更・削除・並び替え
2. カードの作成・編集・削除
3. カードをドラッグ&ドロップでリスト間・リスト内移動
4. カードへのラベル付与（固定カラーセットから色分け）
5. カードへの期限設定（期限切れは見た目で分かるようにする）
6. データはPostgreSQLに保存（リロードしても消えない）

## MVPに含めないもの（将来拡張）
- ユーザー登録・ログイン
- 複数ボード管理
- 検索・フィルタ
- コメント・添付ファイル
- ユーザー定義ラベル（名前・色を自由に作成）
- マルチユーザー対応

## 非機能要件

### パフォーマンス
- カード100件程度でも操作がもたつかないこと（D&Dを含む）

### 対応ブラウザ
- Google Chrome（最新版）を必須対応とする
- Safari・Firefoxは動作確認対象外（将来対応）

### レスポンシブ対応
- デスクトップ（横幅1280px以上）を主対象とする
- モバイル・タブレットは対象外

### データ保持
- データはPostgreSQLに保存し、リロード・サーバー再起動後もデータが失われないこと

### 可用性
- ローカル環境での動作を前提とする（クラウドデプロイは対象外）

## 画面構成

### メイン画面（ボード画面）
- ヘッダー：アプリ名のみ表示（設定ボタンなし）
- ボード領域：リストを横並びで表示
- リスト追加ボタン：ボードの右端に常に表示

### リスト
- リスト名をクリック → インライン編集（Enterで確定、Escでキャンセル）
- ⋮メニュー → 「削除」のみ（確認ダイアログあり）
- リストはD&Dで横方向に並び替え可能

### カード（一覧表示）
- タイトルのみ表示
- ラベルがある場合：タイトル上部に色帯で表示
- 期限がある場合：タイトル下部に日付表示
  - 期限切れ：赤文字 + 背景薄赤
  - 当日：オレンジ文字
  - 期限内：グレー文字
- カードをクリック → 詳細モーダルを開く

### カード詳細モーダル
- タイトル（インライン編集）
- 詳細メモ（テキストエリア）
- ラベル（固定カラーセットから選択するUI、複数選択可）
- 期限日（date picker）
- 削除ボタン（確認なしで即削除）
- モーダル外クリック or ✕ボタンで閉じる（変更は自動保存）

### カード追加
- 各リストの下部に「＋ カードを追加」テキストボタン
- クリックするとリスト下部にインライン入力欄が出現
- Enterで追加、Escでキャンセル

## 次のステップ
1. データ構造（型定義・テーブル定義）を決める
2. 画面のワイヤーフレームを作る
3. バックエンドのプロジェクトセットアップ（Spring Boot）
4. フロントエンドのプロジェクトセットアップ（Vite + React + TS）
5. 実装（リスト → カード → D&D → ラベル/期限の順）
