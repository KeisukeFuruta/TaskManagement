# タスク管理アプリ 要件定義（v1）

## 対象ユーザー
自分一人で使うタスク管理アプリ。ログイン機能なし。

## データモデル
- **ボード（Board）**: まずは固定1ボードのみ対応
- **リスト（List）**: ボード内に複数（例: TODO / 進行中 / 完了）
- **カード（Card）**: リストに属する
  - タイトル（必須）
  - 詳細メモ（任意）
  - ラベル（色付き、複数選択可）
  - 期限日（任意）

## 機能（MVP）
1. リストの作成・名称変更・削除・並び替え
2. カードの作成・編集・削除
3. カードをドラッグ&ドロップでリスト間・リスト内移動
4. カードへのラベル付与（色分け）
5. カードへの期限設定（期限切れは見た目で分かるようにする）
6. データはブラウザのlocalStorageに保存（リロードしても消えない）

## MVPに含めないもの（将来拡張）
- ユーザー登録・ログイン
- 複数ボード管理
- 検索・フィルタ
- コメント・添付ファイル

## 技術スタック
- React + TypeScript（Vite）
- 状態管理: React標準の useState / useContext
- ドラッグ&ドロップ: `@dnd-kit/core`
- データ永続化: localStorage
- スタイリング: CSS Modules、または最小限のCSS

## 次のステップ
1. データ構造（型定義）を決める
2. 画面のワイヤーフレームを作る
3. プロジェクトのセットアップ（Vite + React + TS）
4. 実装（リスト → カード → D&D → ラベル/期限の順）
