# タスク管理アプリ 要件定義（v1）

## 対象ユーザー
自分一人で使うタスク管理アプリ。ログイン機能なし。

## システム構成
- フロントエンド（React）とバックエンド（Java / Spring Boot）を分離した構成
- フロントエンドはREST APIを通じてバックエンドと通信する
- データはPostgreSQLに永続化する
- マルチユーザー対応は対象外（将来拡張）

## MVP範囲
- リスト・カードのCRUD
- カードのドラッグ&ドロップ移動
- ラベル（固定カラーセット）・期限日の設定

### MVPに含めないもの（将来拡張）
- ユーザー登録・ログイン
- 複数ボード管理
- 検索・フィルタ
- コメント・添付ファイル
- ユーザー定義ラベル
- マルチユーザー対応
