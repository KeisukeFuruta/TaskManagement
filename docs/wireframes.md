# 画面ワイヤーフレーム

---

## 1. メイン画面（ボード画面）

```
┌─────────────────────────────────────────────────────────────────────┐
│  TaskBoard    [Board1] [Board2] [Board3]    🔍検索  [＋ボードを追加]  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────────────┐  ┌─────────────────────┐  ┌──────┐        │
│  │ TODO [📅日付][🔥優先度] ⋮│  │ 進行中 [📅日付][🔥優先度] ⋮│  │ ＋  │        │
│  ├─────────────────────┤  ├─────────────────────┤  └──────┘        │
│  │ [緊急] タスクA      │  │ [中]   タスクC      │                  │
│  │ 📅 6/30 🔴          │  │                     │                  │
│  ├─────────────────────┤  ├─────────────────────┤                  │
│  │ [高]   タスクB      │  │        タスクD      │                  │
│  │ 📅 7/5              │  │ 📅 7/10             │                  │
│  ├─────────────────────┤  └─────────────────────┘                  │
│  │ ＋ カードを追加     │                                            │
│  └─────────────────────┘                                            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**ポイント**
- ヘッダー：アプリ名・ボードタブ（アクティブは青いアンダーライン）・検索バー・「＋ボードを追加」ボタンを表示
- リストは横並び、右端に「＋（リスト追加）」ボタン
- リストヘッダーに「📅 日付」「🔥 優先度」ソートボタンを配置
- カード上部の `[緊急]` `[高]` が優先度バッジ
- 期限切れカードは 🔴 で強調（実際は赤背景）
- リストヘッダーをドラッグしてリストを横並び替え可能
- ⋮ メニューからリスト削除が可能

## 2. カード詳細モーダル

```
┌─────────────────────────────────────────────────────────────────────┐
│  TaskBoard                                                          │
├─────────────────────────────────────────────────────────────────────┤
│            ┌──────────────────────────────────┐                    │
│            │ タスクA                        ✕ │                    │
│            ├──────────────────────────────────┤                    │
│            │                                  │                    │
│            │  タイトル                        │                    │
│            │  ┌────────────────────────────┐  │                    │
│            │  │ タスクA                    │  │                    │
│            │  └────────────────────────────┘  │                    │
│            │                                  │                    │
│            │  詳細メモ                        │                    │
│            │  ┌────────────────────────────┐  │                    │
│            │  │                            │  │                    │
│            │  │                            │  │                    │
│            │  └────────────────────────────┘  │                    │
│            │                                  │                    │
│            │  優先度                          │                    │
│            │  [🔴緊急] [🟡高] [🔵中] [🟢低] [－なし]│              │
│            │                                  │                    │
│            │  期限日                          │                    │
│            │  ┌────────────────────────────┐  │                    │
│            │  │ 2026/06/30                 │  │                    │
│            │  └────────────────────────────┘  │                    │
│            │                                  │                    │
│            └──────────────────────────────────┘                    │
└─────────────────────────────────────────────────────────────────────┘
```

**ポイント**
- モーダル外の背景は暗くなる（オーバーレイ）
- ✕ボタン またはモーダル外クリックで閉じる
- 変更は自動保存（保存ボタンなし）
- 優先度は1つだけ選択可能（単一選択）
- 削除はカードの ⋮ メニューから行う（モーダル内に削除ボタンなし）

---

## 3. カードの ⋮ メニュー

```
  ┌─────────────────────┐
  │ [緊急] タスクA   ⋮ │  ← ホバーで ⋮ ボタン出現
  │ 📅 6/30 🔴      ┌──┴──┐
  └─────────────────│↑上へ │
                    │↓下へ │
                    │ 削除 │
                    └──────┘
```

**ポイント**
- カードにホバーすると ⋮ ボタンが右上に表示
- 「↑ 上に移動」「↓ 下に移動」でリスト内並び替え
- 「削除」で即削除（確認なし）
- カードはD&Dでも移動可能（青いラインでドロップ位置を表示）

---

## 4. カード追加（インライン入力）

```
┌─────────────────────┐
│ TODO [📅日付][🔥優先度] ⋮│
├─────────────────────┤
│ タスクA             │
├─────────────────────┤
│ タスクB             │
├─────────────────────┤
│ ┌─────────────────┐ │
│ │ タスク名…       │ │  ← インライン入力欄
│ └─────────────────┘ │
│ [追加] [✕]         │
└─────────────────────┘
```

**ポイント**
- 「＋ カードを追加」クリックでリスト下部に入力欄が出現
- Enterキー または「追加」ボタンで保存
- Escキー または「✕」ボタンでキャンセル

---

## 5. リスト名インライン編集

```
  ┌─────────────────────────┐
  │ [ TODO ] [📅日付][🔥優先度] ⋮│  ← リスト名がテキスト入力欄になる
  ├─────────────────────────┤
  │ タスクA                 │
  └─────────────────────────┘
```

**ポイント**
- リスト名クリックで即座に編集モードへ
- Enterで確定、Escでキャンセル（元の名前に戻る）
