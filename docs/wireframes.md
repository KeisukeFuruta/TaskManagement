---

## 1. メイン画面（ボード画面）

```
┌─────────────────────────────────────────────────────────────────────┐
│  TaskBoard                                                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌───────────────┐  ┌───────────────┐  ┌───────────────┐  ┌──────┐ │
│  │ TODO        ⋮ │  │ 進行中       ⋮ │  │ 完了         ⋮ │  │ ＋  │ │
│  ├───────────────┤  ├───────────────┤  ├───────────────┤  └──────┘ │
│  │ ██████████  │  │ ██████████  │  │ ██████████  │             │
│  │ タスクA     │  │ タスクC     │  │ タスクE     │             │
│  │ 📅 6/30 🔴  │  │             │  │             │             │
│  ├───────────────┤  ├───────────────┤  └───────────────┘             │
│  │ ██          │  │ タスクD     │                               │
│  │ タスクB     │  │ 📅 7/5      │                               │
│  │             │  └───────────────┘                               │
│  ├───────────────┤                                                  │
│  │ ＋ カードを追加│                                                  │
│  └───────────────┘                                                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**ポイント**
- ヘッダーはアプリ名のみ
- リストは横並び、右端に「＋（リスト追加）」ボタン
- カード上部の色帯 `██` がラベルを表す
- 期限切れカードは 🔴 で強調（実際は赤背景）
- ⋮ メニューからリスト削除が可能

## 2. カード詳細モーダル

```
┌─────────────────────────────────────────────────────────────────────┐
│  TaskBoard                                                          │
├─────────────────────────────────────────────────────────────────────┤
│            ┌──────────────────────────────────┐                    │
│            │ タスクA                        ✕ │                    │
│            ├──────────────────────────────────┤                    │
│            │                                  │                    │
│            │  タイトル                        │                    │
│            │  ┌────────────────────────────┐  │                    │
│            │  │ タスクA                    │  │                    │
│            │  └────────────────────────────┘  │                    │
│            │                                  │                    │
│            │  詳細メモ                        │                    │
│            │  ┌────────────────────────────┐  │                    │
│            │  │                            │  │                    │
│            │  │                            │  │                    │
│            │  └────────────────────────────┘  │                    │
│            │                                  │                    │
│            │  ラベル                          │                    │
│            │  [●赤] [●黄] [○緑] [○青] [○紫]  │                    │
│            │                                  │                    │
│            │  期限日                          │                    │
│            │  ┌────────────────────────────┐  │                    │
│            │  │ 2026/06/30                 │  │                    │
│            │  └────────────────────────────┘  │                    │
│            │                                  │                    │
│            │              [ 削除 ]            │                    │
│            └──────────────────────────────────┘                    │
└─────────────────────────────────────────────────────────────────────┘
```

**ポイント**
- モーダル外の背景は暗くなる（オーバーレイ）
- ✕ボタン またはモーダル外クリックで閉じる
- 変更は自動保存（保存ボタンなし）
- ラベルは ● が選択済み、○ が未選択
- 削除ボタンは確認なしで即削除

## 3. カード追加（インライン入力）

```
┌─────────────────────────────────────────────────────────────────────┐
│  TaskBoard                                                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌───────────────┐                                                  │
│  │ TODO        ⋮ │                                                  │
│  ├───────────────┤                                                  │
│  │ タスクA     │                                                  │
│  ├───────────────┤                                                  │
│  │ タスクB     │                                                  │
│  ├───────────────┤                                                  │
│  │ ┌───────────┐ │                                                  │
│  │ │ タスク名… │ │  ← インライン入力欄                             │
│  │ └───────────┘ │                                                  │
│  │ [追加] [✕]   │                                                  │
│  └───────────────┘                                                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**ポイント**
- 「＋ カードを追加」クリックでリスト下部に入力欄が出現
- Enterキー または「追加」ボタンで保存
- Escキー または「✕」ボタンでキャンセル

---

## 4. リスト名インライン編集

```
  ┌───────────────┐
  │ [  TODO    ] ⋮│  ← リスト名がテキスト入力欄になる
  ├───────────────┤
  │ タスクA     │
  └───────────────┘
```

**ポイント**
- リスト名クリックで即座に編集モードへ
- Enterで確定、Escでキャンセル（元の名前に戻る）
