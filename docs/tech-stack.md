# 技術スタック

## フロントエンド
| 項目 | 技術 |
|---|---|
| フレームワーク | React + TypeScript（Vite） |
| 状態管理 | useState / useContext（React標準） |
| ドラッグ&ドロップ | @dnd-kit/core |
| スタイリング | CSS Modules |
| APIクライアント | fetch API（または axios） |

## バックエンド
| 項目 | 技術 |
|---|---|
| 言語 | Java |
| フレームワーク | Spring Boot |
| APIスタイル | REST API |
| ORマッパー | Spring Data JPA（Hibernate） |

## データベース
| 項目 | 技術 |
|---|---|
| DB | PostgreSQL |
| 実行環境 | ローカルインストール または Docker |

## 開発環境
| 項目 | 技術 |
|---|---|
| ビルドツール（Java） | Gradle |
| ビルドツール（React） | Vite |
| Javaバージョン | Java 21（LTS）※当初 Java 25 を予定していたがインストールに失敗したため 21 で進める |
